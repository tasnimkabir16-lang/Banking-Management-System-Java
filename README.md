# Banking Management System

A console-based Banking Management System developed in Java using Object-Oriented Programming concepts.

The application allows users to create and manage bank accounts, deposit and withdraw money, view account information, and review transaction history. It also contains administrative features for viewing and managing accounts.

## Features

- Create new bank accounts
- Automatic account ID generation
- Deposit money
- Withdraw money
- Insufficient balance validation
- View account information
- View transaction history
- Admin password authentication
- View all accounts as admin
- Delete accounts through admin controls
- Input validation
- Thread-safe deposit and withdrawal operations

## Technologies Used

- Java
- Object-Oriented Programming
- ArrayList
- Java Collections
- ReentrantLock
- Exception Handling
- NetBeans IDE
- Apache Ant
